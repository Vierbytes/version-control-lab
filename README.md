# Branching, Merging, and Handling Conflicts

This repo is the website project for the Version Control branching lab. It contains the navigation, hero, contact form, testimonials, and footer. The branch history demonstrates independent header and footer work and resolving their overlapping edit.

GitHub repository: https://github.com/Vierbytes/version-control-lab (private)

## Features

- Navigation links for Home, About, and Contact
- Hero section with a call to action
- Contact form with labeled name, email, and message fields
- Two placeholder testimonials
- Footer with the requested copyright line

## Branch workflow

The required feature branches are `feature/navigation-bar`, `feature/footer`, `feature/hero-section`, `feature/contact-form`, and `feature/testimonials`. The footer and header branches both changed the copyright line; the header branch also added the tagline. Merging both required a manual conflict resolution. `WORKFLOW.md` records the steps and commands used to inspect the branch history.

The GitHub remote is configured. The repo is private, so the instructor will need access to review it.
